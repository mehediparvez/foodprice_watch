## Per-file profiles (schema, rows, coverage, frequency, keys, units, missingness, quality, join to core panel)

### Takeaway
The core panel (TCB Dhaka daily retail prices, 63 item x unit series, 1,412 report days, 76,440 long rows) is clean structurally (no duplicate item-date keys, Avg = (Min+Max)/2 everywhere, 1.42% missing prices), but its time index is report days, not calendar days, it has a 2022 sparse gap, and at least one uncorrected swapped-row error (Palm Olein 2 L, 2025-04-18). Driver files are mostly daily FX/oil, monthly macro/global indices and small hand-curated event tables; none of them carry an item_id, so every join to prices goes through a date (or month) key plus a manual item-to-driver mapping.

- Granularity/coverage summary: daily = TCB (report days), FX (Yahoo 2019-2026-10-22, npm 2024-03-02..2026-10-25, FRED to 2026-10-16), Brent/WTI to 2026-10-20, weather to 2026-10-19 (complete); monthly = IMF to 2026M9, FAO to 2026-09, Comtrade 2021-01..2026-09 (reliable to ~2026-04), remittance 2024-04.., reserves 2024-10..; event intervals with confidence flags. — files as cited in the per-file section
- Missing data (SRC "Still missing"): GloFAS river discharge, US dollar index DTWEXBGS, IFPRI export-restriction tracker (replaced by exporter_policy_events), India domestic retail prices, BB remittance before Apr 2024 and reserves before Oct 2024, bank LC openings by commodity, DAM wholesale prices ("portal returned no data"), hartal/blockade days for 2021-22 and Feb 2026. — [SRC](project://SOURCES_2026-10-26.md)
- WFP (e.g. WFP/HDX monthly Dhaka prices) and AgriPriceBD, named in the project description, are not among the 32 files; DC lists a WFP/HDX cross-check as a TODO. — [DC](project://DATA_CARD.md); project file list

### Inferences
- Lags: monthly global prices (IMF/FAO) are published with ~1 month delay and import pass-through to Dhaka retail is typically weeks to months; Comtrade is reported with multi-month delays (hence the incomplete 2026-05+ months). For a real-time detector, monthly drivers should enter with at least a 1-month publication lag; daily FX/oil should be aligned as-of the report date (last available value). These are standard practice, not documented in the project files.
- Comtrade HS 703 and 910 mix onion+garlic and ginger+turmeric, so they cannot isolate a single TCB item.
- Several event tables are short (import duties only 2024; disruptions only Oct 2023-Nov 2025), so dummies built from them will be zero by construction elsewhere, which a model may misread as "no event".

### Gaps
- No file gives an explicit item-to-driver mapping or lag table; the mapping above is constructed from names, HS descriptions and item_meta.import_origin.
- No AUD/CAD/RUB/UAH FX series for pulse and wheat origins.
- No exporter-country weather beyond Nashik and Cherrapunji; no Brazil/Indonesia/Malaysia weather.

## Data risks an AI must handle (units, Bangla text, date formats, revisions)

### Takeaway
Main traps: report-day vs calendar-day time, inconsistent date formats across files (ISO, DD-MM-YY, YYYY-MM, YYYYMM int, "1980M1"), multi-block or multi-header CSVs, mixed price units within the panel and in news-reported shock magnitudes, Bangla labels with variant spellings and Bangla digits, BOM-prefixed headers, provisional/reconstructed/computed dates, and revisable or stale sources.

### Cited Findings
- Date formats: TCB CSV ISO; item_meta first_date/last_date DD-MM-YY ("17-05-21"); FAO "YYYY-MM" after a title line; IMF "1980M1" with 4 header rows; Comtrade int YYYYMM; BB "YYYY-MM"; bd_food_price_shocks "YYYY-MM"; Ramadan file 2007 Eid al-Adha cell "2007-01-01;2007-12-21". — files as cited above
- Multi-block/multi-header: weather CSV has 2 blocks (metadata + data) and fails a plain read_csv; IMF has 4 header rows and 7 code-less columns plus a duplicated POILAPSP; FAO has a 1-line title. — [weather](file://ATT/db94a33c-weather_open_meteo_13_locations_2019_2026.csv); [IMF](file://ATT/d150ce73-imf_commodity_prices.csv); [FAO](file://ATT/7aa19f49-fao_food_price_index.csv)
- Units: Tk per kg / per litre / per 1, 2, 5 L bottle / per hali (4) / per dista (24 sheets) / per metric ton in the same column; news magnitudes per dozen eggs and per maund; IMF mixes USD/t, US cents/lb, INR-origin chana, EUR/kg (France tomato/apple); Comtrade fob in USD thousand; remittance in USD million and Tk billion; npm xau is ounces per USD. — files as cited above; [DC](project://DATA_CARD.md)
- Bangla text: Product_Bangla 78 variants (incl. new/old crop labels নতুন/পুরাতন), Unit_Bangla includes a numeric typo "50.00-52.00", mixed Bangla (৫) and ASCII (2) digits; holiday_bn column in Bangla. — [panel](file://ATT/9cd963fb-tcb_dhaka_daily_prices_2021_2026.csv); [holidays](file://ATT/c0503c1a-bd_public_holidays_2019_2027.csv)
- BOM: cyclones_floods, political_wage_events and disruption_events start with a UTF-8 BOM (first header becomes "﻿name" unless encoding='utf-8-sig'). — [cyclones](file://ATT/de3733a6-bd_cyclones_floods.csv)
- Confidence flags: event rows are verified / reconstructed / computed; exporter_policy_events is 100% reconstructed; jatka bans all reconstructed; 2027 Ramadan/Eid and 2026-27 holidays computed/estimated (+-1 day). — [SRC](project://SOURCES_2026-10-26.md); [exporter](file://ATT/00ec48ef-exporter_policy_events.csv)
- Stale/revised: Yahoo BDT stale and ~Tk 1.6-1.9 below BB since 2024; Comtrade recent months incomplete and not blanked in the file; FAO/IMF recent months are provisional; weather last day incomplete. — [SRC](project://SOURCES_2026-10-26.md); files above
- Genuine extreme values that break naive transforms: WTI -36.98 (2020-04-20); BDT +6.3% on 2024-05-10; onion log change -0.69 across a 32-day gap. — files above

### Inferences
- An agent should keep a single parsing layer that normalises every date to ISO and every price to Tk per kg/litre/piece, and should carry the confidence flag into features (e.g. down-weight reconstructed events).
- Holidays from the `holidays` package plus Eid gaps observed in the panel should be used to explain missing report days rather than assumed to be data loss.

### Gaps
- Exact FAO/IMF revision vintages are not recorded in the files (only "fetched 2026-10-26" for FAO), so real-time backtests cannot reproduce what was known at each date.
